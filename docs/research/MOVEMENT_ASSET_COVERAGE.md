# Movement animation acquisition audit

Inspected 2026-09-20 for the user's Gears of War 2 movement reference. The goal is an original cover-shooter movement system using licensed source motion, not extracted franchise content. The initial sections record the acquisition audit; the final update records subsequent local integration. Actual gameplay acceptance remains in TEST_MATRIX. The user initially set a **$50 comparison budget**, then allowed research above that amount for a package covering everything. No new maximum or purchase authorization was given. No paid purchase was made. The audit itself did not launch Unreal; the implementation follow-up below did import, retarget and validate selected sources.

## Current result

Eleven official Mixamo clips are now imported and retargeted locally, with four selected for rifle sprint and standing high-wall idle/left/right motion. Seven selected installed Epic clips provide idle, four-way free/high-cover crouch and stationary entry/exit. An earlier local graph passed 24 traversal scenarios in each of two rendered PIE sessions, but a later normal-editor restart auto-reimported 23 Mixamo packages and corrupted all target poses. The source-layout/import-metadata repair is complete and a fresh recovery gate passed 2,013 poses across eleven clips and fourteen package hashes. The recovered graph passed 30 scenarios twice (612 checks), followed by movement (186), blind-fire (68), crouched-reload (224) and polish (242) regressions. Portable fallback also passed 184 checks; post-normal-editor persistence revalidated all 2,013 poses and fourteen package hashes with zero errors/warnings. Final acceptance and limitations are recorded; the earlier pass is excluded. Broader regression results remain in [TEST_MATRIX](../TEST_MATRIX.md). Raw sources and derivatives are ignored, and the committed character stays portable. [LOCAL_MOVEMENT_SETUP](../LOCAL_MOVEMENT_SETUP.md) records reproduction.

A braced knee slide, complete corners/transfers, attached vault, pistol wall poses and knife handling remain unresolved. Acquiring transition clips did not enable those actions. No inspected pack has been shown to cover everything, and no paid pack was purchased.

### Mover dependencies and use boundary

The sequences reference `/MoverExamples/Characters/Mannequins/Meshes/SK_Mannequin`, a separate skeleton package from Gunner's canonical `/Game/Characters` skeleton. Shared Manny naming does not by itself bind these assets to the project skeleton. The crouch packages retain FK Control Rig / Sequencer animation data and preview references. Use Unreal to duplicate/rebind or retarget and verify them; never binary-edit package paths.

The vault montage contains `AnimNotifyState_MotionWarping` / `RootMotionModifier_SkewWarp` references and targets named `VaultStartPos`, `VaultStepPos` and `VaultLandingPos`. Its slot is `DefaultSlot`. `VaultOver` contains a root-motion enable property, but the actual boolean value and root trajectory have **not** been established by the package-string inspection. Unreal inspection must establish the full policy before integration. Do not reuse its montage blindly in Gunner's traversal slot.

Enabling the installed `MoverExamples.uplugin` also enables Mover, ChaosMover, EnhancedInput and CableComponent. Its descriptor and Epic documentation describe experimental sample code/content. The official extended pawn demonstrates vaulting. This is a source-animation opportunity, not a reason to replace Gunner's ACharacter/CharacterMovement architecture or adopt the sample pawn. A content-only local preparation route is preferable to bringing in an unrelated movement stack. [Epic Mover Examples documentation](https://dev.epicgames.com/documentation/en-us/unreal-engine/mover-examples-in-unreal-engine)

The Unreal EULA permits private use and modification of installed licensed technology. Its definition of redistributable Examples specifically names the install's Samples and Templates folders. Engine-plugin content should **not** be assumed to have that same public-source redistribution allowance simply because its plugin is called “Examples.” Keep these original packages and derived animation copies outside the public repository; commit preparation scripts, provenance and hashes instead. [Unreal EULA, sections 1–5](https://www.unrealengine.com/eula/unreal)

### License and public repository handling

The live Kubold, Filmstorm and Solo listings link the **Fab Standard License**. It permits commercial projects, modifications and sharing with project collaborators through a private repository; it does not permit giving away the standalone asset. Preserve the acquisition's actual license and receipt. Do not treat marketplace animations as Epic installed Templates or CC0. [Fab Standard License summary and agreement](https://www.fab.com/eula)

If acquired, place the untouched source/archive under `Saved/AssetResearch/<Publisher>` and import original packages plus retargeted/modified derivatives into a clearly excluded tree such as `Content/Gunner/Licensed/<Publisher>`. Add the exclusion **before** import, and verify `git check-ignore` on representative original and derived files. Keep a recoverable local backup. Commit only authoring scripts/manifests and project-authored composition that does not embed third-party source motion. A fresh checkout must detect missing licensed content and report preparation steps, rather than silently pretending a complete movement pack is included. This is a proposed integration boundary; this audit did not change `.gitignore` or create runtime assets.
